# Contributing to Indian Army HQ Secure Link Dashboard

## Security Notice
This is a secure military communication system. All contributions must follow strict security protocols.

## Development Setup
1. Fork the repository
2. Clone your fork: `git clone <your-fork-url>`
3. Install dependencies: `npm install`
4. Start development: `npm start`

## Code Standards
- **React**: Functional components with hooks
- **Styling**: Tailwind CSS classes only
- **Security**: All code must pass DLP compliance
- **Mobile**: Responsive design required
- **Testing**: Manual testing with demo credentials

## Pull Request Process
1. Create feature branch: `git checkout -b feature/description`
2. Make changes following code standards
3. Test on both desktop and mobile
4. Submit PR with detailed description
5. Await security review and approval

## Security Requirements
- No external API calls
- No data logging to external services
- DLP compliance mandatory
- Blockchain integrity maintained
- Authentication security preserved
